### 🐺 Про мене

- 🛠️ Роблю продукти **від ідеї до деплою**: бекенд, адмінка, мобільний клієнт, десктоп і Docker-збірка, все сам.
- 🧩 Люблю брати знайомі сервіси й робити **свою версію під себе**: Notion, Loom, n8n, Directus, Termius, Sentry, Typebot. Усе це в мене вже є у власному виконанні.
- 🏭 Основний фокус — **бізнес-автоматизація**: модульна CRM/ERP з обліком, складом, POS-касами, транспортом, тех. картами, правами доступу та імпортом з 1С/Prom.
- 🎮 Для душі роблю **ігри про Україну**: козацьке село XVIII ст., плем'я кам'яної доби, ферма, таксі вулицями реального міста. 3D-моделі генерую кодом у Blender.
- 🤖 Вбудовую **ШІ** всюди, де воно справді допомагає: локальні моделі через Ollama, голос → документ, розпізнавання накладних, відеоаналітика на YOLO.
- 🔌 Підключаю софт до **реальних пристроїв**: зарядна станція по BLE, міні-дисплей на столі, віртуальний робот з обличчям і голосом.
